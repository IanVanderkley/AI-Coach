# Coaching navigation and defaults

- The game review and Ask your coach views are separate. The conversation uses existing deterministic verified follow-up; no paid AI is enabled and Ranked conversations remain memory-only.
- Settings → Replay & interface contains browser-local default disclosure choices. Progress expansion continues to use its existing remembered view state, and changing its setting updates that state.
- Practice/Ranked/progress cards share a visual shell. Suggested lesson actions lead to the relevant replay, and quick drill can open directly.
- No database migration or competitive data changes.
