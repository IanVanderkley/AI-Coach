# Batch 28D.3 — Bounded constraint enumeration

Experimental standalone `enumerateVisibleBoard(rows, columns, mineCount, board, limits?)` in `lib/coach/constraint-enumeration.ts`. No production caller is changed. Do not merge its classifications into existing move grades until proof presentation and performance have been verified.

The frontier is every covered square touching a revealed number. Enumerate binary assignments to this frontier, pruning any assignment that cannot satisfy a visible clue or the public mine total. Covered squares outside the frontier have no individual clue constraints: an assignment is feasible exactly when its remaining mine total is between zero and the size of that outside region. All compatible full layouts are represented by this search without explicitly enumerating outside permutations. A frontier square is forced if every feasible frontier assignment agrees; outside squares are forced only if every feasible assignment leaves zero mines or fills the entire outside region. Player flags and covered adjacency values are ignored. Terminal mine exposure is excluded.

Hard caps: 18 frontier cells and 100,000 visited search nodes per invocation. Optional limits can only lower these caps. `limited`, `invalid`, `inconsistent`, and `terminal` return no claims. `complete` indicates exhaustive enumeration within the visible clue and public total model. No probabilities are returned: `frontierModels` counts feasible frontier assignments, not equally weighted full-board layouts. Future probability work must weight assignments by the number of compatible outside arrangements and state its prior assumptions. A complete result with no safe covered square does not establish that every possible action must be a guess under all gameplay-specific rules.

The isolated test corpus enumerates every mine layout and subset of revealed non-mines for 2x2, 2x3 and 3x3 (synthetic snapshots, not necessarily reachable by game rules). Across 11,461 unique snapshots, enumeration matches all 48,765 forced-square classifications, including 108 missed by the opt-in overlap solver. No wrong claims or misses on that corpus. Max visited nodes: 251. Tests also cover limits, flags, hidden adjacency, off-frontier deductions, inconsistent evidence, terminal snapshots and empty frontiers on the three real board dimensions. Large nonempty frontier coverage and actual replay performance are still pending. There is deliberately no proof UI or grading integration in this step.
