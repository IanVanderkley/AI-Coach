# Batch 28 — Advanced Coaching

## Interactive board analysis
- Make Before and After replay boards interactive.
- Allow players to select individual squares.
- Explain why a square is safe, a mine, or unresolved.
- Highlight supporting clues and connected deductions.
- Synchronize selected squares across both boards.
- Provide step-by-step visual explanations.

## Personalized learning
- Improve learning progress statistics and trends.
- Identify recurring mistake patterns.
- Develop personalized training plans.
- Create interactive Minesweeper pattern exercises.
- Improve square-specific coaching conversations.

## Requirements
- Use only evidence available at the selected board state.
- Never present an uncertain deduction as proven.
- Preserve Ranked integrity and existing security boundaries.
- Keep paid AI disabled unless explicitly approved.
- Support all board difficulties and mobile layouts.
