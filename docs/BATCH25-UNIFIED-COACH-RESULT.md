# Batch 25A.4 — Unified completed Practice coaching

The selected review, history grade, checkpointed compatibility POST and its offline fallback all derive their scores and findings from the shared post-opening analysis. The legacy API keeps its unstamped request path for older recordings and examples. Checkpointed requests bypass the legacy provider/quota path and return only deterministic findings; the verified focus endpoint retains the existing paid quota gate. The whole-recording verified brief keeps its schema and count semantics; focus selection uses post-opening evidence so it cannot select a setup action absent from the workspace. Move IDs remain raw recording IDs. A grade and score may be null when the evidence cannot establish a decision. The compatibility metrics field is null rather than publishing conflicting legacy counts. The real review no longer offers the experimental report; sample demos remain separate.

This does not migrate old reports, change the learning-score formula, enable paid AI, or change Ranked or the database. The legacy analyzer remains for unstamped compatibility, and its output is not checkpoint-verified. No claim of server authenticity is made for client-recorded Practice games.
