# Board controls guide preference (Batch 27C.2)

Settings → Replay & interface → Gameplay interface → Show board controls guide.

Enabled by default. This browser-local preference hides the shared instructional footer in Practice and Ranked, including its Ranked clock reminder, without changing the timer, board controls, keyboard instructions, gameplay, review legend or rewards. It works for signed-in and guest players, persists across refresh and navigation, and synchronizes between tabs on the same origin. It does not sync across accounts, devices, or local/staging origins. Storage failure retains the default or last readable choice and reports a failed save.

No schema, API, dependency, or game logic changes.
