# Batch 25D — Private, versioned personalized coaching (first release)

- Explicit Save coaching report on a completed game review. Server accepts only source and game identifier, verifies signed claims plus a live session, scopes by owner, reconstructs the recording and writes only a versioned learning snapshot. Ranked shares the exact same authorized recording store as the read-only recording endpoint. Practice is player-recorded, not competitively verified. The score, findings and exact classified mistake move numbers come from the shared post-opening analysis. No board layout or moves are copied into report storage; original source foreign keys cascade on game/account deletion.
- Unique owner/mode/game/version key: reopening does not write, resaving replaces that version (hash and saved time included); new analysis versions can be stored alongside older ones. Practice sources may be edited by their owner, so a saved snapshot is from the time of save; reopening replays the current source. For a guest or an unsaved handoff, save the Practice game to an account and select it from history. Saved account-game result links are used once the account save finishes. The existing immediate handoff remains available while saving.
- Report generation is capped at 1,000 moves and normal board dimensions; 6 saves per account per fixed minute, distinct from Ranked gameplay quotas. History lists up to 100 current-version reports per mode, no replay/provider calls, private/no-store. Older versions remain stored but are not mixed into trends. Practice history pruning cascades reports; trends cover retained, explicitly saved reviews, not every game ever played. No score inference from unreviewed games.
- Learning panel filters mode, difficulty and 10/25/50/100 reviewed-game windows. Counts distinct games and occurrences, recurring focus requires at least two games, and uncertainty is excluded from proven decision accuracy. Accuracy comparison uses equal recent/older halves (minimum five per half); odd middle game is omitted from comparison. Ungraded games are not zero-scored. Sample coverage is shown. Saved findings can reopen their original replay and move. Initial personalized exercises are deterministic single-question checks and three-game practice plans, not a full tutorial engine or AI-generated curricula.
- All report/counter tables are RLS enabled with no browser grants; service role only. Both endpoints reject invalid origin and unauthorized/revoked sessions. No competitive writes, no paid AI requests. No hosted migration until local acceptance and release readiness.

## Local acceptance

1. Apply migration only to local Docker, run the SQL regression, format/build/typecheck/test. Verify same-owner save for Practice and Ranked, resave without duplicates, reload history, reopen saved report and individual move. Confirm Practice handoff remains usable.
2. Guest cannot save or read account reports; second account sees no first-account report, foreign Ranked/Practice ID returns 404; active/abandoned Ranked save returns 404. Browser roles cannot access either new table or save quota function. Invalid/cross-origin payloads rejected. Verify 429 for save quota.
3. Save two or more legitimate same-difficulty games, select filters/windows, compare against saved findings, exercise correct/incorrect drill, check empty and partial data, mobile and keyboard. Confirm competitive fingerprints unchanged and no provider usage. Real-player usefulness testing is still required; do not claim a complete public validation before it occurs.

## 25D.6 usability refinement

- The learning panel remembers only display preferences (expanded, mode, difficulty, window) in browser local storage and opens by default. Reports stay server-owned. Exact current-version status is fetched for a selected game even when it is not among the 100 recent list entries.
- The saved button is a toggle: POST saves, DELETE removes only the authenticated owner's snapshots for that mode/game (all versions), never the source recording or any competitive data. Both mutations require same origin, verified live session and the shared six-per-minute report mutation quota. Service role receives DELETE through a separate additive migration; browser grants remain absent. Status reads and deletions are private/no-store and foreign or nonexistent snapshots are indistinguishable.
- Saved reports are expanded by default inside the learning panel, with a visible Open replay and Review move action when evidence exists. A first proven mistake can suggest a preliminary lesson, and a general starter drill is shown for saved games without proven mistakes. Recurrence still requires two distinct games. Mobile controls wrap rather than overflowing. Browser/mobile acceptance must be confirmed locally.
