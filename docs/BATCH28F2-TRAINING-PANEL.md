# Batch 28F.2 — Interactive training boards

Baseline: 28F.1, commit a3ffbb1. Dedicated, initially collapsed Interactive training panel on the Coaching history screen, between learning progress and match history. No sign-in requirement. Six fixed starter exercises cover guaranteed mine, guaranteed safe, uncertain square, comparing clues, and checking an existing flag. The complete visible-board definitions contain no answer keys or hidden mine layouts; all answers are derived by the 28F.1 engine. Difficulty labels are introductory curriculum labels, not measured player skill.

The training header and card use the same typography, spacing, surface token and border geometry as the existing Coaching history cards. The panel prepares the catalog only on first expansion, then retains the active exercise while collapsed. Desktop action exercises use left-click to reveal and right-click to flag; the wrong mouse button does not submit an attempt. Right-click suppresses the context menu on answer squares only. Touch/pen taps and keyboard Enter/Space use the requested action. Classification remains an explicit choice. A correct flag choice displays a flag, while a correct reveal choice displays a checkmark instead of inventing a newly revealed clue. Native buttons submit answers, non-answer squares remain read-only, classification highlights a fixed target, and feedback is textual as well as visual. The board stays unchanged after an answer. One attempt is accepted until retry or navigation; previous/next never wrap, and navigation clears feedback. A correct answer is not a gameplay reveal. Returning to a different page/review or reloading can reset this transient session. No history, storage, database writes, competitive rewards, AI calls, or dependencies added. Progressive hints, proof explanations, personalized exercises and saved training progress are deferred to later checkpoints.
