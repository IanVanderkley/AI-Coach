# Batch 28D.5 — Advanced square coaching

Post-game only: when the original square analysis is unresolved, the player can explicitly run advanced analysis. The same visible evidence snapshot used by the basic analysis is used (before the move, or after the opening reveal). The result is retained for the same game/snapshot and reused across inspected coordinates. Changing games or moves cannot display stale results. Clicking the analysis action pauses playback. No automatic advanced search is performed during replay playback, and no existing solver, grading, live gameplay, API, database or provider code changes.

The opt-in overlap solver provides traced proofs; completed bounded enumeration can independently establish certainty or model-conditional risk. If an independent complete search disagrees with a rule result, the advanced panel suppresses its claims. The overlap lesson highlights real visible evidence with A-only, B-only and shared groups, previously proven cells and the conclusion; any third union clue is identified. If the displayed overlap is a prerequisite rather than the final deduction, this is explicitly labeled. The full dependency chain is available separately. Enumeration-only conclusions show exact compatible layout counts, not a fictional local proof diagram.

Probability assumes uniform compatible full-board layouts, not calibrated game generation odds. Nonzero risks never round to zero or 100%. Alternatives exclude flagged squares, and are compared using exact numerators. Lower risk does not imply guaranteed safety. Incomplete search yields no percentages; valid rule proofs may still be displayed. Invalid, inconsistent, and terminal inputs are unavailable. Advanced results do not change the original replay overlays or grade. The original square analysis remains visible as the basic result.

The advanced work runs synchronously only after explicit activation. Full-size replay performance, browser interaction and potential worker offloading are reserved for 28D.6.
